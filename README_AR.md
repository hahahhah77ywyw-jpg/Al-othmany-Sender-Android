# Al-othmany Sender Android 4.1.0

هذه النسخة تنقل **منطق** الحماية والاستئناف من إضافة v148.9.43 إلى Android، ولا تنسخ كود WhatsApp Web الداخلي.

## التشغيل
1. ابنِ المشروع في Android Studio.
2. ثبّت APK.
3. افتح التطبيق واختر WhatsApp.
4. فعّل خدمة Accessibility لـ Al-othmany Sender.
5. أضف روابط دعوة.
6. إذا أردت النشر، فعّل النشر واكتب الرسالة.
7. ابدأ التشغيل.

## آلية الأمان
- لا يتقدم المؤشر قبل نتيجة نهائية.
- ثلاث محاولات للرابط ثم تأجيل ذكي مرة واحدة، ثم فشل مسجل.
- حفظ المؤشر والحالة محلياً.
- لا تعتمد عمليات WhatsApp على إحداثيات الشاشة.
- النشر لا يتم إلا بعد الوصول إلى شاشة محادثة يظهر فيها حقل كتابة الرسالة.

## ملاحظة
توافق Accessibility مع WhatsApp قد يتغير إذا غيّر WhatsApp أسماء عناصر الواجهة أو بنية الشاشة. كما أن Dual Messenger / Work Profile قد يفرض قيوداً من Android على اكتشاف ملف المستخدم الآخر.
